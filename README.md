## 🚀 Getting Started

### 📋 Prerequisites

Make sure you have the following installed before the first class:

---

### 🐍 Step 1 — Install Python

<details>
<summary><b>🪟 Windows</b></summary>

1. Go to [https://www.python.org/downloads/](https://www.python.org/downloads/)
2. Click **Download Python 3.x.x** (latest stable version)
3. Run the installer — ✅ **Check "Add Python to PATH"** before clicking Install
4. Open Command Prompt and verify:

```bash
python --version
```

</details>

<details>
<summary><b>🍎 macOS</b></summary>

```bash
# Using Homebrew (recommended)
brew install python

# Verify
python3 --version
```

</details>

<details>
<summary><b>🐧 Linux (Ubuntu/Debian)</b></summary>

```bash
sudo apt update
sudo apt install python3 python3-pip -y

# Verify
python3 --version
```

</details>

---

### 🖊️ Step 2 — Install VS Code

1. Visit [https://code.visualstudio.com/](https://code.visualstudio.com/)
2. Download for your OS and install
3. Open VS Code and install the **Python Extension**:
   - Press `Ctrl + Shift + X`
   - Search **"Python"** (by Microsoft) → Click **Install**

**Recommended Extensions:**

| Extension | Purpose |
|-----------|---------|
| 🐍 Python (Microsoft) | Syntax highlighting, IntelliSense |
| 🔍 Pylance | Type checking & auto-complete |
| 🎨 One Dark Pro | Beautiful dark theme |
| 📁 Material Icon Theme | Better file icons |
| 🤖 GitHub Copilot | AI coding assistant |

---

### ⚙️ Step 3 — Set Up Your First Python File

```bash
# 1. Clone this repository
git clone https://github.com/saifullah857/python-with-saif

# 2. Open in VS Code
cd python
code .

# 3. Create a test file and run it
echo 'print("Hello, Python With Saif!")' > hello.py
python hello.py
```

✅ If you see `Hello, Python With Saif!` — you're all set!

## 💡 Python Quick Reference

```python
# ✅ Hello World
print("Hello, World!")

# ✅ Variables
name = "Saif"
age = 22
is_student = True

# ✅ Data Types
x = 10          # int
y = 3.14        # float
z = "Python"    # str
lst = [1, 2, 3] # list

# ✅ Conditional
if age >= 18:
    print("Adult")
else:
    print("Minor")

# ✅ Loop
for i in range(5):
    print(f"Day {i+1}")

# ✅ Function
def greet(name):
    return f"Hello, {name}!"

print(greet("Saif"))
```
